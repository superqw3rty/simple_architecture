# Homework #1 — TV Shows Explorer

Небольшое приложение для поиска и просмотра сериалов на публичном API TVmaze.

API: `GET https://api.tvmaze.com/search/shows?q=<query>` → `[{ score, show: { id, name, genres, image, rating, premiered, summary, ... } }]`

## Цели задания

1. Закрепить Simple Architecture на практике.
2. Создать собственные AI Rules на основе Simple Architecture (`AGENTS.md`, `docs/ai/`).

## Чек-лист требований

### 1. Поиск
- [ ] Изначально — пустой список и только поле поиска.
- [ ] Пользователь вводит запрос → приложение получает результаты от TVmaze.
- [ ] Фильтрацию по запросу выполняет API (на клиенте по тексту не фильтруем).

### 2. Список и пагинация
- [ ] Шоу отображаются списком или карточками.
- [ ] Пагинация по **3** элемента на страницу.
- [ ] Можно переключаться между страницами.

### 3. Фильтр по жанрам
- [ ] Уникальные жанры собираются из текущей выдачи.
- [ ] Жанры показаны над списком кликабельными чипсами.
- [ ] Выбор жанра оставляет только шоу этого жанра.
- [ ] Фильтр можно сбросить и вернуться ко всем результатам.

Пример: запрос `Murder` → 10 шоу; клик по `Comedy` → остаются только 2 комедийных.

### 4. UX и дополнительное
- [ ] Запрос не уходит на каждую букву (debounce).
- [ ] Предыдущий запрос отменяется при новом вводе.
- [ ] Есть состояния загрузки и ошибки (с повтором), «ничего не найдено».
- [ ] Собственный дизайн.
- [ ] Challenge: запросы реализованы без `useQuery`.

### Архитектура
- [ ] View без логики, вся логика в презентерах.
- [ ] Файлы ≤ 120 строк.
- [ ] Древовидная структура компонентов.
- [ ] `pnpm check` зелёный.

## Принятые продуктовые решения

- Жанр выбирается один; сброс — чип «All» или повторный клик по активному.
- Смена запроса сбрасывает жанр и страницу; смена жанра сбрасывает страницу.
- Пагинация скрыта, если страница одна.
- HTML из `summary` вырезается, `dangerouslySetInnerHTML` не используем.
- Переход Start → Results: фокус в поле и ввод ничего не двигают. Раскладка меняется один раз — когда запрос ушёл (после debounce): hero плавно сворачивается (~300 мс), поле поиска переезжает в шапку, не теряя фокус и каретку. Очистка поля возвращает hero. При `prefers-reduced-motion` — без анимации.
