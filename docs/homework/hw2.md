# Homework #2 — From Frontend to Fullstack

Продолжение TV Shows Explorer: свой backend, перенос на него части логики, кеширование и избранное. План по шагам — `hw2-plan.md`, решения — D-54…D-62 в `docs/ai/decisions.md`.

## Чек-лист требований

### 1. AI Rules
- [x] Правила обновлены по лекции 2: слой Tasks (`tasks.md`), `logic/` (`structure.md`), роутинг (`routing.md`), backend (`backend.md`), журнал D-54…D-62.

### 2. Backend
- [ ] Свой сервер (`server/`, Hono).
- [ ] Пагинация на сервере (3 шоу на страницу).
- [ ] Фильтрация по жанрам на сервере; счётчики жанров — по всей выдаче.
- [x] Обращения к TVmaze только с сервера; фронт ходит в свой `/api`.

### Кеширование
- [ ] Кеш — обычный объект `const cache = {}` в памяти сервера (сделан на `Map`, D-64).
- [ ] Тот же запрос к TVmaze в течение 5 минут отдаётся из кеша.
- [ ] Нет кеша или он устарел — запрос к TVmaze и обновление кеша.
- [ ] Ошибка TVmaze не кешируется.

### 3. Избранное
- [ ] У каждого шоу есть звёздочка: добавить в избранное / убрать.
- [ ] При добавлении и удалении — toast-уведомление (и при ошибке).
- [ ] Кнопка (ссылка) с количеством избранных шоу.
- [ ] По нажатию — страница со списком избранного (`/#/favorites`), из неё можно убрать шоу.
- [ ] Вся логика избранного — на backend, хранение — объект `const favorite = {}` в памяти.
- [ ] У каждого браузера своё избранное (`X-Client-Id`, D-59).

### 4. Архитектура
- [ ] Компоненты разложены по `logic/{hooks,utils,tasks}` (D-55), `pnpm check:arch` это проверяет.
- [ ] Бизнес-логика — в тасках (фронт: `toggleFavorite`; сервер: `searchShows`, `fetchWithCache`, избранное), без React.
- [ ] Запись данных — через таски, без `useMutation` (D-56).
- [ ] Навигация — только в презентерах; поиск (`q`, `genre`, `page`) в URL, «Назад» со страницы избранного возвращает ту же выдачу.

### UX и качество
- [ ] Макеты нового функционала в Figma согласованы, вёрстка им соответствует (D-62).
- [ ] Состояния загрузки, ошибки с повтором и пустого списка — и на поиске, и на избранном.
- [ ] Звезда доступна с клавиатуры (`aria-pressed`), toast объявляется скринридером.
- [ ] Тесты: кеш, поиск, избранное на сервере; таска `toggleFavorite` на фронте.
- [ ] `pnpm check` зелёный, skill `arch-review` без нарушений.
- [ ] API развёрнут (Oracle Cloud), фронт на GitHub Pages работает с ним по HTTPS.
