# Доступность (a11y)

Цель — WCAG 2.2 AA. Разметку проверяет `eslint-plugin-jsx-a11y` (recommended, все `src/**/*.tsx`, D-44); остальное — чек-лист `arch-review`.

## Разметка

- Интерактив — на нативных элементах (`button`, `a`, `input`), а не на `div` с `onClick`.
- У каждого поля есть подпись, у иконочной кнопки — `aria-label`.
- `aria-pressed` — только у переключателя. Чип без `isActive` — обычная кнопка: проп не задаётся, атрибут не рендерится.
- Группа однотипных кнопок (чипы) — `role="group"` с `aria-label` или `aria-labelledby` (id — `useId()` в презентере).
- `<ul>`/`<ol>` получают `role="list"`. **Почему:** глобально `list-style: none`, а Safari с VoiceOver такие списки списком не объявляет. ESLint это исключение знает.
- На каждом экране ровно один `h1`, уровни заголовков не пропускаются.
- Картинка, которая дублирует соседний текст (постер рядом с названием), — `alt=""`. Число без подписи (рейтинг со звездой) дополняется скрытым текстом через `@include visually-hidden`.

## Фокус

- Видимый фокус (`:focus-visible`) не убирается. Индикатор — `box-shadow` плюс прозрачный `outline`: он нужен, чтобы фокус был виден в forced-colors.
- **Фокус не теряется.** Если действие удаляет из DOM элемент в фокусе или делает его `disabled`, презентер **до** изменения состояния переводит фокус через `ref` на элемент, который останется: поле ввода, заголовок результатов или `<main>`. Цели, на которую нельзя попасть по Tab, ставится `tabIndex={-1}` и `:focus { outline: none; box-shadow: none; }`.
  **Почему:** иначе фокус падает на `<body>`, и пользователь клавиатуры или скринридера оказывается в начале страницы.

  ```ts
  // ❌ кнопка «›» на последней странице становится disabled, фокус теряется
  onPageChange: setPage,

  // ✅ useResults.ts
  const onPageChange = useCallback((next: number): void => {
    setPage(next);
    headingRef.current?.focus();
  }, []);
  ```

## Объявления

- Смена статуса загрузки и результатов объявляется через `aria-live`. Регион рендерится всегда, меняется только его текст — короткая фраза, а не весь список (D-37).

## Цвет

- Текст — контраст не ниже 4.5:1 к фону, на котором он лежит; граница поля ввода — не ниже 3:1 (D-43). Значения из Figma, не проходящие порог, правим в `tokens.scss` и фиксируем в `decisions.md`.
